## 🚀 Featured Projects

### 🔨 AuctionPlatform

A full-stack online auction application built with a React frontend and Spring Boot microservices.

* JWT authentication using HttpOnly cookies
* REST APIs and API Gateway
* Redis and Redisson for fast bidding and concurrency control
* MySQL for persistent storage
* Apache Kafka for asynchronous auction notifications
* Email notifications for auction outcomes

**Tech:** Java, Spring Boot, React, MySQL, Redis, Kafka, Docker

🔗 [View Project](https://github.com/Harshal-belgamwar/auction-platform)
